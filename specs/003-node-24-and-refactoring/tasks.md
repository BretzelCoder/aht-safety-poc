## Notes
- **Order**: lot 1 first, because it is small and deliverable alone; lot 2 is built so that every commit is green. The key trick: T-11 and T-12 restructure *in place*, then the files are cut from the top of the single script in its own order (T-16 to T-24), so each commit leaves a page that works and a `compare-traces` that says "identical".
- **Moving a chunk** always means: create the file (French header with `@concern`, `'use strict'`, the code verbatim, registration line last), add the tag in load order and the manifest line, remove the chunk from the inline script, run `node scripts/stamps.mjs`, run the whole suite and `compare-traces`. Tests that locate code do so through `readPage`.
- **Deliberate breakages** are made in the working copy (or on a copy in a temporary folder), run, then reverted at once with `git checkout --`; none is ever committed.
- **A failing scenario, invariant or trace** stops `/implement` and goes back to the spec, after re-measuring at the model's own step (0.02 s), threshold and over enough seeds (CLAUDE.md, "Re-measure before declaring a gap").
- **Granularity** (decision 6 of the plan): if 22 script files feel too many while moving, T-17 to T-24 can merge files (the spec has no size rule); the map and the checks follow whatever is in the tags.
- **Push** at T-04 and T-36 only after asking; pull request and merge only on the owner's explicit request.
- **A-8**: a task that adds a check lists its breakage in "Done when"; the breakage is run and recorded before the box is ticked. **A-10**: any new browser test that reads state refreshed by an animation frame polls for the model-derived value.
- **Acceptance coverage**: AC-1 T-02 · AC-2 T-02, T-04 · AC-3 T-01, T-02 · AC-4 T-04, T-36 · AC-5 T-03 · AC-6 T-09, T-10, T-25, T-36 · AC-7 T-06, T-25, T-36 · AC-8 T-29, T-30, T-36 · AC-9 T-28 · AC-10 T-27 · AC-11 T-25 · AC-12 T-26 · AC-13 T-31 to T-34 · AC-14 T-14, T-15, T-16 · AC-15 T-13, T-14, T-27 · AC-16 T-28 · AC-17 T-12, T-16 · AC-18 T-06, T-16, T-17 · AC-19 T-30 (before), owner after the merge.
